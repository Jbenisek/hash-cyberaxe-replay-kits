# What an exact fraction does—and does not—prove

Extract the ZIP, enter `sparsedoor-price-kit`, and run:

```text
python -I -B replay.py
```

Python 3.10+ and its standard library are sufficient. No solver, compiler,
network, project drive or historical ledger is needed. The replay creates
disposable synthetic windows, relocates one hardcoded directory in a copied
script and checks eight interface behaviors. It never changes the original
source or reads the live research ledgers. Each copied invocation has a
ten-second timeout; the combined harness has a 45-second timeout.

## The accounting boundary

The historical calculator combines window means and sample deviations with
two fixed tail-rate choices. It rounds work with floor and ceiling, then uses
Fraction for the final scalar work expression. The fractions represent the
already-rounded calculation exactly; they do not make the sampled estimates,
inherited probability, floating operations or transferred attack model exact.

The calculation omits the sparse-head construction. Its dated leaderboard
constants are historical context, not current records. A successful run is
not a complete attack-price certificate and not an exact success lower bound.

## Synthetic results, not attack scores

The positive fixtures contain either 24 or 73 artificial windows, each with
100 operations, ten claws and five groups. Both have zero sample variance
and print mu+=100, c-=10 and r-=0.5. The two resulting **toy** price outputs
are 108.16402 and 109.22982. Do not use these as measured or claimed attack
scores. The test's purpose is to make the program's input and arithmetic
contracts observable without consuming or modifying live data.

The negative controls show that unsupported sample counts, an empty window
set, zero claws and an empty JSON array fail. A high-variance fixture prints
a negative claw lower estimate before a logarithm fails. An extra array
element is silently ignored because only each file's first element is read.

Run the wrapper rather than the archived price.py directly: the original
contains a historical absolute path and has no command-line path option.
The wrapper's manifest checks source integrity before execution and rejects
optimized Python mode. All fixtures exist only in temporary directories.

## Reuse and credit

Original project source:
`research/game/climber/guided/sparsedoor/price.py`. Its comments identify the
r39 ledger formula and the sparse-door accounting comparison. This lesson
documents the interface and limitations; it is not a new cryptanalytic result.
No real sample is recounted and no probability premise is verified here.

To reuse the calculator scientifically, first specify the intended sampling
law, defend the transferred tail rate and price the entire head-plus-tail
procedure. Require positive meaningful bounds and independently check the
ledger selection. Exact-looking output cannot replace those proofs.
