Run with Python 3.11 or newer, standard library only:

This finite teaching kit recomputes eight complete integer ledgers from an
independently written rational model, checks all 64 possible six-flag subsets,
and encloses the logarithms used for upward-rounded displayed costs.
It does not run an attack, allocate a large table, install anything or use
the network. No imported competitor source or proof is redistributed.

Why the bit walk is lossless
---------------------------
The only candidate flag positions are 38+42j for j=0..5. For nonzero fired,
ctz(fired) selects the least such position p. The lane shift is p-38=42j.
Replacing fired with fired AND (fired-1) removes exactly this flag, without
changing any other set bit. Induction visits all and only the fired lanes,
in increasing order. The empty mask skips the loop. All 64 subsets are also
checked explicitly. This proof does not itself authorize ctz as one operation.

Six counted operations per fired lane require the proposed lowering:
ctz (1) + position adjustment (1) + clear-lowest-bit (2) + loop test (2).
Caller setup, final exit, extraction, live registers and spills must fit the
unchanged complete program charge. The source's 6 is not proved merely by
timing Python bit_length, and changing a ledger constant is not an implemented
port. The original success model also retains sampled channel coefficients.

Interpretation
--------------
Use this kit to inspect the arithmetic and sensitivity to per-lane price.
Use a separate complete implementation/charging proof before treating the
conditional row as claim-ready. Correct integer arithmetic does not certify
the inherited success probability or memory law. The source comparison is
to archived 4d1f5387; it is not a live ranking.

The replay uses exact Fractions for charge terms and ceiling operations.
Decimal ln is correctly rounded; adjacent decimals and directed division
enclose log2(N/C). Both ends must round upward to the same displayed value.
This certifies the displayed rounding for the modeled rational N/C only.
