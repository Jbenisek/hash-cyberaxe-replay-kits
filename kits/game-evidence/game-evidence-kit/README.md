# From game events to scientific evidence

Extract this kit, enter `game-evidence-kit` and run `python replay.py` with
Python 3.10 or newer. No external Python packages, network or solver required.
The verifier refuses `-O`, checks all distributed file hashes and replays the
numerical compression traces independently of the original meter driver.

Expected: 70 saved closure measurements, 57 distinct ordered pair-and-step
identities, 33 standard-IV records, zero collisions. The other 37 records use
a common chosen chaining value within each pair. Padding eligibility is not
checked. These records overlap other research exports; do not add their count
to the library's independently deduplicated collision totals.

`game-research.json` includes:

- 293 saved signed-difference hash groups covering 1,417 saved game records.
  The original writer hashes the expanded signed difference to twelve hex
  characters. Grouping by that key is not a proof of full instance equivalence.
  Records may be dependent or duplicated across exports. Sixty-nine local
  schedule-score fields are unknown, not zero. Scores are heuristic model
  values, not complete attack prices.
- 70 exact raw numerical message pairs and shared initial values, with their
  final four A/E-row mismatch counts. Those eight words are exactly the final
  working-state registers, so the four-row sum is checked against the full
  256-bit state. Recomputed feedforward outputs are also retained.
- 70 reported two-bit-checker horizon entries: 24 numeric, 46 unknown. A local
  horizon observation is not a proof of global feasibility, a maximum possible
  cutoff or a complete characteristic. The original horizon job is not rerun.

The observed terminal-state mismatch range is 109–149 bits. The value 128 is
only the half-different-bit reference for a hypothetical uniform 256-bit XOR;
this selected data set is not proved to follow that distribution. A small
distance alone does not give a probability of finding a collision.

The verifier checks three standard SHA-256/hashlib known answers and one-bit
mutation controls. All 70 rows are independently recomputed; the saved group
and horizon tables receive arithmetic/schema checks, not solver proof checks.
The reference implementation retains its original project/HASH$CyberAxe attribution.

The data projection retains source-relative filenames, source hashes and
numerical evidence. It omits player, wallet, machine, free-form note, raw shot
identifier, route and job-control fields. Raw game logs are not bundled. No
external papers/PDFs, ordinary user-agent conversations, live controls or new
contest claims are included. This is a historical teaching set, not a new
collision discovery or a blanket redistribution license.
